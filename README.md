## 2. 동양 오행(五行)과 색채 체계의 원리

동양 전통 철학에서 우주 만물은 **목(木), 화(火), 토(土), 금(金), 수(水)**의 다섯 가지 기운으로 이루어져 있으며, 각 기운은 고유한 상징 색상과 에너지를 지닙니다. 십이지(十二支) 띠 역시 각각 독자적인 오행 특성을 내포하고 있습니다.

* **목(木) - 청색/녹색계열:** 성장을 상징하며 쥐, 범, 토끼 띠의 창의성과 새로운 시작을 돕습니다.
* **화(火) - 적색/분홍계열:** 열정과 확장을 나타내며 뱀, 말 띠의 명예운과 에너지를 끌어올립니다.
* **토(土) - 황색/브라운계열:** 포용과 안정을 의미하며 소, 진(용), 미(양), 술(개) 띠의 신뢰도와 중심을 잡아줍니다.
* **금(金) - 백색/실버계열:** 결단과 결실을 뜻하며 원숭이, 닭 띠의 직관력과 재물운을 강화합니다.
* **수(水) - 흑색/네이비계열:** 지혜와 유연함을 의미하며 돼지 띠의 통찰력과 정서적 안정을 지원합니다.

본 계산기 알고리즘은 사용자의 출생 연도와 띠에 내재된 오행의 강약 및 상생(相生)·상극(相剋) 관계를 다각도로 분석합니다. 나를 상극하는 기운은 완화하고, 부족한 기운은 색채를 통해 보완(상생)함으로써 개인의 운성 에너지를 한 단계 끌어올리는 원리로 작동합니다.
